# Гильдия и корона — прототип 0.5.1

Откройте index.html или самостоятельный файл «Гильдия-и-корона-0.5.1.html». Установка и сеть не нужны.

## Новое в 0.5.1

- На новой карте только дом, гильдия, таверна и центральный склад; четыре жителя и два случайных героя. Каждый новый дом добавляет четырёх жителей. Старые города сохраняются при загрузке.
- В таверне доступны четыре кандидата, включая целителя. Найм стоит 100 золота из казны однократно. Жалование пока не реализовано.
- Лесничий: три рабочих, радиус четыре клетки. Посадка занимает 25 секунд, затем дерево растёт 120 секунд; взрослое дерево содержит восемь единиц древесины. Рост медленнее вырубки. Назначьте работников через контекстное меню.
- Кнопка Ⅱ приостанавливает работу здания; ▶ возобновляет. У дома остановленные жители не работают, у склада останавливается доставка, у таверны — обслуживание и выплата, у гильдии — новые контракты и отправка. Начатые походы продолжаются. Уже высаженные деревья растут естественно и при паузе лесничего.
- Дом, гильдия, таверна, склад и алтарь не требуют ручного назначения работников. Производствам, включая кузницу, нужны жители. Свободные жители автоматически доставляют грузы; в верхней строке учитываются только доставленные ресурсы.
- Дороги находятся в меню города и стоят пять камней за клетку. Инструмент остаётся активным для следующих клеток; Escape завершает строительство. НПС ходят по земле, дорога ускоряет движение на 25%.
- Алтарь строится в черте города и содержит одну ячейку для погибшего. На надгробии нажмите «Вернуть в город», задайте награду ползунком и разместите контракт. Без свободного работающего алтаря действие недоступно. Ячейка резервируется за одним контрактом.
- Герой занимает телом одну клетку рюкзака, приносит его на алтарь и идёт в таверну за наградой. После поднятия тела контракт нельзя отменить до доставки. При гибели носильщика тело остаётся в месте его смерти.
- Нажмите ✚ на алтаре: воскрешение доступно, если в городе есть живой целитель. Возвращается тот же герой со своим именем, инвентарём и экипировкой, с половиной здоровья. Автоматического воскрешения нет.
- Смерть ломает три случайных целых надетых предмета, либо все доступные, если их меньше трёх. Сломанные вещи не дают бонусов. Ремонт в работающей кузнице с работником стоит 50 личного золота героя за предмет и занимает восемь секунд. Герой чинится самостоятельно в свободное время; также доступна кнопка в окне персонажа.

## Сохранение и управление

Нажатие на объект открывает единое меню; сведения раскрываются кнопкой i, действия — круглыми значками. Нажатие снаружи, Escape и движение камеры закрывают меню. Игрок задаёт цель и награду, герои сами собирают отряд. Туман мастера меняет только отображение, а не знания героев. Лучники и маги противника замедляют цель попаданиями, включая отступление.

Сохранение: guild-crown-v051, с загрузкой доступных сохранений v5/v4. Миграция сохраняет здания и героев, пересчитывает население по домам. Разные браузеры и файловые адреса могут разделять localStorage. Для нового старта нажмите «Новая карта»; это заменяет текущее сохранение после подтверждения.

## Проверка и исходники

node tests-v051.cjs — новый старт, население, доставка без дорог, стоимость дороги, паузы, посадка/рост, найм, возвращение тела в одной ячейке, резервирование алтаря, выплата, условия воскрешения, поломка, ремонт и сохранение.

node build.cjs — сборка самостоятельного HTML. Браузерная проверка Edge/Playwright: меню, найм, контракт, доставка, воскрешение, отображение сломанных вещей, размеры мобильного меню. Ошибок JavaScript не обнаружено.

Загрузка скриптов: engine-core-v3 → engine-v3 → engine-v4 → engine-v5 → engine-v051 → app-v051 → ui-v3 → ui-v4-051 → ui-v5 → ui-v051. Все слои нужны. docs/ — Markdown-заметки для Obsidian.

Это локальный одиночный прототип. Telegram, сервер, PvP и пошаговое окно боя ещё не реализованы. Следующий согласованный этап — разнообразие экономики и жалование героев.
